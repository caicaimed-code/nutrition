# Dad's Nutrition

A simple daily food and nutrition tracker, installed on the phone's home screen as a web app.

Live app: https://caicaimed-code.github.io/nutrition/

## Install on a phone
- iPhone (Safari): open the link, tap Share, then Add to Home Screen.
- Samsung / Android (Chrome or Samsung Internet): open the link, open the menu, then Add to Home screen or Install app.

Food entries are saved on the phone itself, not in this repository.
